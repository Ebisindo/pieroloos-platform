# PIEROLOOS

Corporate Intelligence & Formation Platform for PieroloCorp International LLC.

## Foundation session 01

This package establishes the product repository, official supplied logo, responsive application shell, restrained cosmic visual system, initial routes, typed domain foundation, Prisma schema scaffold, documentation, and CI skeleton.

## Start locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Product loop

Client Intake → Business Profile → Jurisdiction Lens → Formation Roadmap → Compliance → Report Generator → Engagement Records.
