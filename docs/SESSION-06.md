# Session 06 — Jurisdiction Intelligence Engine

## Pipeline
Business Profile → Jurisdiction Universe → Criteria + Weights → Evidence → Normalized Factors → Analytical Indicator → Comparison Snapshot → Professional Review

## Core principle
An analytical indicator is not a conclusion. The UI must expose criterion, weight, factor value, evidence, confidence, review date, assumptions, and methodology.

## Snapshot principle
Persist the exact jurisdictions, criteria, weights, factors, evidence references, methodology version and timestamp used for a comparison so historical reports remain reproducible.

## Future expansion
Jurisdiction rule packs, source monitoring, evidence freshness, formation workflows, regulatory calendars, provider intelligence, scenario simulation and knowledge graph.
