# Client Intake Architecture

## Principle

Client Intake is the controlled entry point into PieroloOS's corporate workflow.

It should create structured, reusable information rather than a static form submission.

## Information lifecycle

1. Capture
2. Validate
3. Classify
4. Persist
5. Review
6. Transform into Business Profile
7. Feed downstream workflows

## Downstream consumers

- Jurisdiction Lens
- Formation Roadmap
- Compliance
- Reports
- Engagement Management

## Data integrity

The system must preserve:
- what the user said
- what the system derived
- what remains unknown
- what requires professional review

The system must not silently promote assumptions to facts.
