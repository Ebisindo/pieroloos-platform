# Jurisdiction Lens Methodology

Evidence classes:
- E0 Unknown
- E1 User provided
- E2 Secondary evidence
- E3 Primary evidence
- E4 Cross-verified

For jurisdiction J and criterion C:
normalized factor ∈ [0,100]
weighted contribution = normalized factor × criterion weight
analytical indicator = sum(weighted contributions) / sum(weights)

Missing information is not zero. Unknown remains Unknown.

The indicator is an internal comparison output only. It must not be represented as a legal, tax, regulatory, banking or other professional conclusion.
