# PieroloOS — Session 06
## Jurisdiction Lens / Corporate Jurisdiction Intelligence Engine

Session 06 introduces the first intelligence-oriented domain engine.

It stores jurisdiction profiles, criteria, evidence, assumptions, confidence, review dates, transparent analytical indicators, user-defined weighting, and reproducible comparison snapshots.

This is a decision-support engine, not a legal, tax, regulatory, banking, or professional-advice engine.
